# Feature-Spezifikationen (Archiv)

Jeder Ordner hält fest, wie ein Feature mit Spec Kit entstanden ist: Anforderung (`spec.md`),
Entscheidungen (`research.md`, `plan.md`), Aufgaben (`tasks.md`) und Prüfszenarien. Die Dokumente
beschreiben den Stand **zum Zeitpunkt der Umsetzung** und werden danach nicht mehr gepflegt;
Datei- und Funktionsnamen darin können veraltet sein.
